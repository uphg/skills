## 2026-08-25 — 标题编号策略反转

维护者讨论结论：中文数字标题体系（`一、` / `1.1` / `1.1.1`）对日常 markdown 文档过重。编号重复了 `#` 层级已编码的信息，每次结构调整都要全部重排，还可能与文档平台自动编号冲突。策略反转：默认裸标题，仅条款需被引用的正式文档才手工编号。

### 变更清单

### 1. `SKILL.zh.md` → 重写步骤 2

- 步骤更名为「应用标题层级」。
- 默认改为所有语言一律裸标题（此前仅英文如此）；删除中文数字层级示例块。
- 补充默认理由：信息重复、重排成本、diff 噪音、平台自动编号冲突。
- 新增扁平化指引：若 `####` 频繁出现，应拆分或重组而非加深层级。
- 「总结」末章约定保留，移入默认规则列表。
- 新增例外分支：仅当条款需被引用（合同、法规、标准、公文、学位论文）或印刷模板要求时才编号；必须使用一套完整体系——公文式（`一、` → `（一）` → `1.` → `（1）`）或小数式（`1` → `1.1` → `1.1.1`），严禁混搭；工具侧可编号时优先交给工具。

### 2. `SKILL.md` → 同步

英文版同步以上修改，结构与中文版一致。
